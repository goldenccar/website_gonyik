# 面料数据库本地审阅

本地地址：http://127.0.0.1:5180/fabrics/catalog 。尚未发布。

## 页面与卡片

- Hero 复用全站 editorial 组件，整幅背景；图片、标题、副标题仍由页面配置维护。
- 次级导航沿用专业支持页的共用选择器。列表按 CMS 系列顺序排列。
- 面料系列 mega menu 左栏直接进入数据库；右栏保留系列入口。
- 桌面三列、中屏两列、手机一列。正面采用上图下文，保留型号、类型、功能及三条刻度。
- 刻度两端为“日常—专业”“轻薄—厚实”“柔软—挺括”；保留原有后台位置数值。
- 反面呈现型号、面料说明、适用方向和咨询入口。详细规格仅后台维护，公开接口不再返回 specifications。
- 移除扫光动画造成的溢出；正反面共享网格单元，不再使用卡片内部滚动。
- 移除无实物图时的英文小字；缺图型号保留中性占位，等待上传真实样品照片。
- 点击翻面不触发系列定位滚动；链接携带 SKU 时仍可自动展开。

## CMS 对应

| 内容 | 后台位置 |
|---|---|
| Hero 与适用方向标题 | 页面配置 → 面料数据库 |
| 菜单入口、顺序、图片跟随 Hero | 页头导航 → 面料系列 |
| 型号、类型、图片、功能及三条刻度 | 面料管理 → 编辑面料 |
| 反面说明与适用方向 | 面料管理 → 翻面：面料说明 / 翻面：适用方向 |
| 详细参数 | 面料管理 → 详细性能数据（仅后台） |

审阅内容：catalog-local-content.json。显式本地迁移脚本：scripts/apply-catalog-review.ts；执行前备份，重复运行保留后续 CMS 编辑。不得把本地审阅数据整库覆盖生产。

## 对标依据

- [GORE-TEX](https://www.gore-tex.com/en_uk/technology/gore-tex-products)：先给核心功能，再展开附加特点；借鉴信息层次，不移植其性能承诺。
- [eVent](https://eventfabrics.com/)：技术系列和成品展示分层；港翼的系列介绍与具体型号目录仍保持分工。
- [DEEPBLU DRYFLASH+](https://deepblutextiles.com/zh/dryflash/)：具体型号使用紧凑面料图与编号入口，避免宽卡片挤入过多小字。

## 验证

31 项测试通过，类型检查与生产构建通过，质量审计无阻断项。浏览器验证桌面三列、390px 手机单列、正反面切换和无横向溢出。现有 6 个型号均已配置可编辑翻面说明；仅一个型号有现成图片。
