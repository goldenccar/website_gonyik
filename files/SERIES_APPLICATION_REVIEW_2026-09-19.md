# 三个面料系列与产品应用页：修改意见

> 历史讨论稿：其中 OTTER / RAYO 按功能分界的建议已被后续决定替代。当前以专业户外 / 轻户外的产品定位区分，两者具有共同功能维度。请以 PRD 与 SERIES_BENEFITS_2026-09-20.md 为准。

2026-09-19。基于本次生产版本、实时公开目录、页面实际浏览，以及用户已说明的业务情况。本文是讨论稿，没有将以下建议应用到网站。

## 1. 先明确这四页分别解决什么问题

系列详情页应帮助客户判断“我的产品是否适合用这个系列”；产品应用页应说明“这种面料可以怎样进入具体产品”。RPO-Tech 已经承接材料与工艺原理，系列页无需再复制一套技术介绍。

建议保留路径：使用需求 → OTTER / RAYO / KAIS → 应用与样品 → 咨询。具体型号放在后段作为进一步选择，完整 TDS 和报告仍定向提供。不是每个访客都需要先进入面料数据库。

页面长短服从已有内容。三个系列共用字体、间距、图文尺度和按钮规则，但不要求同样多的模块、同样三个卖点或同样一套动画。

## 2. 当前页面的具体问题

| 页面 | 实际看到的内容 | 对访问者的影响 |
|---|---|---|
| OTTER | 面料水珠大图；高性能防水透湿；金奖膜技术与 SGS 检测介绍；三个性能标签；进入面料数据库 | 先讲技术背书，没先解释适用穿着与选用理由；与膜技术页重叠 |
| RAYO | 防晒、导湿与凉感；纤维配方和织物结构；UPF 50+、导湿速干、接触凉感；数据库入口 | 所有特征被写成整条系列的共同承诺，不利于容纳轻薄复合面料、披风手感开发等不同方案 |
| KAIS | 特种场景材料平台；消防、防化及其他专业任务；多材料协同、项目化开发 | 表述范围很大，反而看不到现在已在开发的软性防割、防刺材料 |
| 产品应用 | 成衣/配件一级分类，日常通勤/户外防护/专业与特种二级分类；7 个公开条目；直接链接型号 | 分类和占位比实际案例丰富，容易被看作成衣商品目录，而不是材料应用展示 |

当前应用目录还有几个需要先修正的事实层问题：

- 7 个公开条目中，只有“男士通勤夹克”配置了产品图；另外 6 个用 APPLICATION STUDY 占位，名称在图片区和正文区重复出现。
- “配件”及下属养护用品、穿戴配件、功能组件均没有公开条目，进入后主要看到咨询入口。
- “水域披风”目前关联 OTTER T50，标签为耐盐雾、防水、透湿。它不能直接等同于用户提到的钓鱼防晒披风开发；是否同一项目尚未确认。
- “超轻量防晒服”标签是轻量化、防风、透气，没有直接解释防晒与导湿；应用名称、标签和实际面料能力需要重新对应。
- 目前“采用面料”暗示确实已经采用；对于仅适用方向，应改为“适用系列”或“建议面料”，不要将设想写成成品事实。
- OTTER 当前公开型号包括 T50，但用户主要送样名称为 T50-2。后续应核对命名映射，不在本轮研究中直接改码。

依据：[OTTER](https://gonyik.com/fabrics/series/otter)、[RAYO](https://gonyik.com/fabrics/series/rayo)、[KAIS](https://gonyik.com/fabrics/series/kais)、[产品应用](https://gonyik.com/equipment)。公开目录快照保存在本地 `preview.local/series-application-research.json`。

## 3. 三家竞品的启示，各取什么

### GORE-TEX：先让人理解系列的使用价值

PRO 页面用攀登场景和适用条件开场，随后说明耐用、防水、透湿与防风，再呈现结构、测试入口和采用该技术的品牌产品。优点是材料说明始终对应使用结果。港翼可以借鉴阅读顺序和场景摄影，不照搬庞大的成品筛选器、品牌阵容或它的保证承诺。[GORE-TEX PRO](https://www.gore-tex.com/technology/gore-tex-products/pro)

### eVent：系列定位、少量特征与具体产品相连

alpineST 页面用简短定位、功能要点和材料说明引向应用产品；stormburstLT 明确描述轻量、活动自由度与应对小雨雪，而非把所有天气防护混为一谈。它的轻量系列仍可采用复合技术，这说明“轻量系列”与“是否有膜”并不是同一个分类维度；这不能推出 RAYO 应拥有相同的性能。[alpineST](https://eventfabrics.com/waterproof/alpinest/)、[stormburstLT](https://eventfabrics.com/weatherproof/stormburstlt/)

eVent 的成品目录明确显示制造品牌与采用的技术。港翼应学它把材料和产品连起来，但当前没有同等规模的已上市合作产品，不能照搬商品目录。[Explore the Gear](https://eventfabrics.com/explore-the-gear/)

### DEEPBLU：离面料供应商的询样路径最近

DRYFLASH+ 的实际页面依次出现系列说明、性能解释、微观机理、系列产品和索样入口；DRYBLOCK+ 同样把系列定位、使用方向与样品申请连起来。港翼可以借鉴“理解系列后很快能咨询样品”，不用复制其长技术段落、较长表单与样品购物车。竞品机理和性能主张是它自己的表述，本次不将其视为经过独立核验的技术证据。[DRYFLASH+](https://deepblutextiles.com/zh/dryflash/)、[DRYBLOCK+](https://deepblutextiles.com/zh/dryblock/)

对港翼的组合建议：GORE-TEX 的用途叙事、eVent 的系列边界、DEEPBLU 的询样入口。不要再为每个系列重复完整技术平台。

## 4. OTTER：重点从“金奖膜”回到“防水透湿面料怎么用”

建议定位保持“防水透湿”。首屏可用“适用于冲锋衣、雨衣等户外服装”这样的直接说明，不让型号或奖项承担开场介绍。

| 模块 | 放什么 | 布局与取舍 |
|---|---|---|
| 首屏 | OTTER、定位、短用途说明；“咨询面料”与页内“了解应用” | 保留现有全屏比例和品牌风格；后续有合适实拍时，用真实穿着场景替换单纯水珠微距。水珠图留给面料细节 |
| 穿着需求 | 防雨与排出湿气这两个核心问题；手感、挺括程度、耐磨需求作为选材差异 | 一组大图配两段短文，不做六张功能卡、不堆“全天候、极致、全面” |
| 用于哪些产品 | 冲锋衣、雨衣等有明确开发基础的方向；通勤防雨外套可作为同系列用途 | 2—3 个有区分的应用。只有设计方向时明确标作应用示意，不宣称客户成品 |
| 材料依据与咨询 | RPO-SOTEX 膜和复合结构的一段摘要；膜技术链接；咨询和现有面料入口 | 原理展开交给 RPO-Tech。奖项、PFAS 检测若保留，放在这里并限定对应对象 |

不主推某一型号，但也不用完全隐藏型号入口。T50-2 可在“现有面料”里出现，帮助已决定了解 OTTER 的采购继续沟通。

## 5. RAYO：按轻户外穿着需要定义，不按结构定义

建议继续用“防晒与轻户外”作为入口定位。系列页重点讲日晒、出汗、长时间穿着时对轻薄和手感的要求。不要将“无膜”“某一种科技纱线”写成系列边界。

这里需要保留一条明确的产品归属判断：**若客户选它的主要理由是防水透湿，优先 OTTER；若主要理由是防晒、导湿、轻薄与穿着感，优先 RAYO。** 极轻薄 OTTER 不能只因为克重小就全部移入 RAYO，否则两个系列仍会混淆。膜与复合只是实现方式。

| 模块 | 放什么 | 布局与取舍 |
|---|---|---|
| 首屏 | RAYO、防晒与轻户外、一句用途说明 | 明亮的日晒/轻活动场景，与 OTTER 的雨天画面区分；不另换一套视觉系统 |
| 轻薄穿着与导湿 | 以目前 30D、约 85 g/m² 的防晒导湿面料作为内部内容锚点 | 前台讲需求与实际样品，不必把规格做成大号数字。展示布料垂坠、弯折、贴肤侧的真实细节 |
| 一个开发实例 | 钓鱼防晒披风提出的手感需求；如何通过复合方式做出面料样品 | 优先一组样布/手感对照图配短说明。当前已知的是面料样品完成，不写成披风成品已量产 |
| 选材与咨询 | 根据目标产品选择防晒、导湿、手感等具体能力 | 用简短文字交代不同面料侧重不同；主按钮“咨询 RAYO 面料”，技术链接为次级入口 |

UPF、速干、接触凉感分别绑定到有依据的面料。30D 面料已说明防晒与导湿，但不能仅据此补写“凉感、抗菌、超快干”。这页可以有两种材料思路，但先不创造新的子系列名字。

## 6. KAIS：把专业防护说具体，页面可以最短

“专业防护”可作为一级定位；正文围绕当前软性防割、防刺材料开发来讲。消防、防化与防割、防刺对应不同风险和验证要求，不能作为一串可互换的专业词。

| 模块 | 放什么 | 布局与取舍 |
|---|---|---|
| 首屏 | KAIS、专业防护；“面向防割、防刺需求的柔性材料开发”作为候选说明 | 用真实材料叠层、弯折或专业装备局部。无需枪械、火场、军人库存图制造气势 |
| 核心样品 | 当前 UPE 织物与芳纶毡复合开发，重点是柔性结构与具体防护需求 | 一幅材料大图或简洁结构图，配一段正文。约 320 g/m² 为当前样品信息，不当作整系列恒定指标 |
| 项目沟通 | 目标防护要求、测试条件、穿着部位与结构适配 | 一个咨询入口；需要原理的人再去高性能纤维/复合技术页，不补长篇通用工艺说明 |

目前已知送检处于准备阶段。未确认前不写“通过公安部认证”“军工级”“某防刺等级”，也不把材料样品表现等同于完整防护服表现。RPO 可以作为港翼材料技术命名，但不要把 UPE 写成一种化学上全新的纤维。

在这个阶段，KAIS 三个模块足够。专业感来自材料、用途和证据的准确对应，而不是比 OTTER 更长的页面。

## 7. 产品应用页：从商品网格转为少量应用展示

现有“产品应用”名称可以保留。建议副标题候选：“了解港翼面料在不同产品中的用法。”不要在没有相应内容时继续枚举鞋履、配件等品类。

推荐页面结构：

1. **短首屏**：真实应用或样品大图，加一句页面说明。页面任务是快速看产品形态，不必再次用完整一屏让访问者等待正文。
2. **精选应用**：先做两组有内容的图文——防水外套与防晒/轻户外穿着。软性专业防护在具备可公开素材后加入，可使用真实材料样品，不必等成衣上市。
3. **更多应用方向**：确有内容再增加。现有少量条目不需要两级筛选；数量增长后再启用筛选。隐藏空分类，而不是删掉后台已有分类与映射。
4. **应用开发咨询**：最后保留一个入口，咨询时自动带入当前应用方向。现有表单足够，不另造样品购物车。

每个应用条目只回答四件事：是什么产品、在什么环境使用、面料解决什么问题、对应哪个系列。比如防晒披风应先讲日晒和手感，再链接 RAYO；不是只列三个功能标签然后要求客户识别 RAYO 30。

视觉建议采用大图配短说明，宽屏两列或交错图文；不要继续把一张窄卡片一分为二，造成图片和文字都局促。背景延续白/浅灰与深蓝，仅用现有细线和少量强调色组织层级。一个好样品可以占据一组完整图文，没必要拆成三张重复卡。

必须区分三种内容状态，标注要短、自然：

| 实际情况 | 对外呈现 | 材料关系用语 |
|---|---|---|
| 已完成并允许公开的客户/自有成品 | 应用案例，注明可公开的品牌与产品 | 采用面料/采用系列 |
| 已完成的面料或产品样品 | 开发样品，说明完成的是哪一层 | 样品采用/样品材料 |
| 尚未制作的使用设想 | 应用方向，配示意图并标注 | 适用系列/可选面料 |

这些是内容状态，不必再做一套复杂前台分类。后台增加一个状态字段即可；系列关联优先，型号关联可选。“RPO 高性能材料”若每张卡都反复出现，识别价值有限，可移到次级信息或详情说明。

## 8. 后台、性能与审阅顺序

后台沿用现有系列与应用模块，避免新建平行数据源。系列内容需要可维护的短模块：标题、正文、媒体/图注、链接、显示顺序。应用增加内容状态和直接系列关联，并保留可选 SKU 关联；同一应用在系列页和应用页读取同一记录。

不改变字体。优先压缩静态图片，正文图片按需加载，减少大视频和自动轮播；需要表现弯折或手感时才加入一个短视频，首屏有静态封面。不要为了“高级感”同时下载三条系列影片。

建议逐页审阅次序：

1. OTTER：确定共用的图文尺度、场景说明与询样路径。
2. RAYO：明确轻户外定位与披风样品的呈现方式。
3. KAIS：收紧到真实专业防护开发，核对可公开的样品/送检状态。
4. 产品应用：整理真实案例、样品与应用方向，再做布局。

本轮研究不要求立即补齐所有素材。先删重复和错位表述，再用已有真实内容把页面讲清楚；不足以支撑一个模块时就不放。
