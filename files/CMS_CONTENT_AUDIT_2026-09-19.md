## 数据对应

- 系列名称/顺序/主图/说明：fabric_series → bootstrap → 系列页。
- 特点及图标：story_highlights 与 story_icons 一一对应；最多六项，后台空行成对过滤。
- 系列按钮：story_primary_label/link 与 story_secondary_label/link；非法协议拒绝保存。
- 技术入口：home_config.platform_cards 每项携带自身媒体类别与目的链接。
- 共享媒体：home_config.technical_visuals → 首页与 RPO 动画组件。
- 首页系列说明：home_config.series_entries；与系列详情分开维护，不互相覆盖。

## 保留边界

- 按钮箭头、图标线形、动画轨迹、颜色与排版属于设计实现；后台选择图标/动画类型，不编辑 SVG 源代码。
- 关闭、保存、错误提示等通用交互词属于界面语言；公开业务标题、说明、按钮内容及图片路径不以组件默认文案兜底。
- server/db.ts 与 src/config/rpoContent.ts 中历史初始化/迁移内容仍保留，供旧库升级和内容追溯；RPO_CONTENT 不被公开页面作为渲染回退使用。
- 旧系列路由和公开 API 保留兼容，不能因为当前前台未调用就判定为废代码。
- 未清除上传文件或历史媒体。媒体删除需通过引用检查，不能只靠本轮页面是否展示判断。
- 页脚两个导航列仍按当前主导航顺序分组，是结构性配置限制；正文与目的链接来自 CMS。本轮未改页脚信息架构。

## 验证

27 项测试通过，包括系列 CMS 保存、部分更新、清空、图标配对、非法链接拒绝，以及首页入口重排/删除和媒体配置重复迁移保护。类型检查、生产构建、质量审计通过：零未引用组件、零确定性废导出、无资源超预算。浏览器另验收大屏、普通桌面、手机和首页/RPO共享媒体。

迁移仅作用于 preview.local/production-preview-db.json：apply-series-screens.ts（v4）与 apply-home-media-cms.ts（v1）；各自保存备份，重复执行不覆盖后续 CMS 修改。生产发布时需要另行应用经确认的数据变更，不能只发布代码。
