# 港翼材料科技模块：逐页文案与布局方案

版本：V1，2026-09-19。状态：审阅稿，尚未实施。

基线：本地已同步的线上版本 `462ca42`，公开内容快照时间 2026-09-19。本稿提出页面改法，不代表下列能力、数据、图片和证书已完成发布核验。

## 1. 本轮结论与范围

材料科技采用“一个 RPO 技术平台概览＋五个独立板块”：膜技术、高性能纤维、复合技术、供应链、测试与认证。

RPO 是港翼技术平台的总名称。平台涵盖材料选用、纱线与织物开发、复合加工、供应链协同和测试验证。所有用于开发的纱线与纤维都可以进入“高性能纤维”板块，不按采购来源分栏。页面重点展示港翼开发的面料及其表现；“RPO 技术平台”与具体“RPO 纤维”的名称、材料身份分开使用。

本轮调整六个材料科技页面，以及 Header、页内导航、Footer 中与这些页面有关的入口。系列页只规定内容分工和链接位置，完整重做另按页审阅。保留已认可的首页、配色、字体系统和主要组件；首页材料平台入口只更新名称和落点。

### 1.1 三类页面的职责

| 页面 | 核心问题 | 内容深度 |
|---|---|---|
| OTTER / RAYO / KAIS 系列页 | 适合什么用途，为什么选这个系列 | 场景、使用价值、相关面料；技术用短解释和链接 |
| 材料科技 | 如何开发，性能从哪里来，如何验证和交付 | 原理、工艺、代表性成果与验证方式 |
| 面料卡片 | 这一款适合什么，与其他款有什么不同 | 具体用途、手感、结构特点、精选性能与咨询 |

可以在多个地方提及同一项技术；完整解释集中在对应专题。完整 TDS 和报告仍定向提供。

### 1.2 现有内容的去向

| 现有内容 | 处理 |
|---|---|
| 无氟技术体系 | 退出独立主导航。材料选择的简述并入概览；膜材料与相关检测放在膜页；不保留长篇法规与环境背景作为进入技术内容的必经页面 |
| RPO 高性能材料平台 | 改为平台概览，清楚呈现三项材料工艺能力与两项保障能力 |
| 膜技术 | 保留；缩短重复原理说明，增加精选性能成果位置 |
| 高性能纤维 | 保留名称；从单一 RPO 纤维介绍扩展为纤维、纱线与织物结构开发 |
| 复合技术 | 保留；从固定三层防水结构扩展到不同材料组合和目标手感 |
| 供应链管理 | 独立保留；围绕开发到量产，减少与纤维页重复的合作伙伴介绍 |
| 测试与认证 | 独立保留，名称统一；分清测试结果、第三方检测、证书资质与研发奖项 |

## 2. 全模块的布局与交互

### 2.1 页面骨架

六页共用：首屏 → 材料科技页内导航 → 主体内容 → 相关系列或咨询。

- 技术页首屏保留现有摄影与深色遮罩风格。建议桌面约 480–560px、手机约 320–400px，并按文字内容自动增高。这是技术页规格，不改变首页全屏大图。
- 首屏左对齐：一个 H1、一段不超过两句的副标题。只在有明确下滑目标时放一个文字链接。
- 页内导航显示：平台概览 / 膜技术 / 高性能纤维 / 复合技术 / 供应链 / 测试与认证。沿用现有吸顶行为，位于 Header 下方，不新增第二套章节吸顶栏。
- 正文沿用站点现有外侧对齐线。大图可以占整行，长段正文控制在约 30–42 个汉字一行；超宽屏不无限拉长文字。
- 每页采用一处主要图解或成果展示，其他部分用图文段落、细分隔线和轻量列表组织，不把所有信息装进同样的白色卡片。
- 白色作为主体底色，雾灰用于区分相邻内容；海军蓝用于主标题、导航状态和必要的重点区域。取消连续多层“灰底套白框套小卡片”。
- 图像优先使用真实材料、样布和加工细节。沿用图片前核对身份：合作方厂房、实验室明确标注对应名称，不标成港翼自有。

### 2.2 字号、密度和交互

优先复用现有 `type-hero`、`type-section-title`、`body-copy` 等全局样式，不另造字体体系。以下是本模块审阅目标：

| 项目 | 桌面 | 手机 |
|---|---|---|
| 正文 | 18–20px，行高 1.7–1.85 | 16–18px，行高约 1.75 |
| 图注、方法、来源 | 14px 左右，行高约 1.6，保持清晰对比 | 13–14px，允许自然换行 |
| 大章节间距 | 72–96px | 40–56px |
| 标题与正文 | 16–24px | 12–16px |
| 图文两栏间距 | 40–64px | 改单栏，间距 24px |

正文一般为一至两段；单个模块以一项问题为中心。性能结果突出数字和名称，测试对象及方法放在同一视觉区域。关键条件不用 hover 才可见。

仅复合页保留一个用于切换结构示例的 tab；其他页优先直接展示，避免多个轮播和交互叠加。技术图默认静态可读，动画只解释方向或层次，关闭动画后仍能理解。手机页内导航横向滚动、保留边缘提示并让当前项可见；页面本身不横向溢出。

- 标题：**膜与面料的实际表现**
- 引导：**从功能膜到复合面料，分别观察材料性能与成品表现。**

- 标题：**纤维、纱线与织物，一起设计**

### P03-04 开发方向

- 标题：**不同用途，关注不同表现**

- 链接：**了解 RAYO** → RAYO 系列页。

该案例由用户提供的已完成样品事实支撑。建议拍港翼自身样布的折叠、悬垂与手持细节，不展示客户身份、客户商标或未经许可的成衣参考样。不写“已达到某性能”或“已量产”。无可公开照片时保留短文，使用准确标注的结构示意。

### P04-03 结构示例

|---|---|---|---|

### P04-04 工艺关注点

下方仅三条短说明：

- **层间结合：**结合材料与用途，检查粘合及后续使用中的表现。
- **功能保持：**确认复合后的面料是否达到预定功能要求。
- **成品手感：**对比柔软度、挺括感与悬垂表现，继续调整方案。

不公开胶配方和具体工艺参数，不承诺未经核实的洗涤次数。若已有可公开的对比样片，可用两张等尺寸实拍作为补充；不额外添加装饰数字仪表。

## 7. P05｜供应链

**任务：**回答客户“怎样从需求推进到样品和量产”。页面用实际工作环节与可交付资料建立可信度。

**布局顺序：**首屏 → 开发流程 → 环节衔接 → 量产关注点 → 咨询。

### P05-01 首屏

- 标题：**供应链**
- 副标题：**衔接材料、织造、染整与复合，推进从样品开发到量产的各个环节。**
- 图片：沿用经过身份确认的生产细节图。合作工厂外景须有准确图注。

### P05-02 工作路径

- 标题：**从需求到量产**
- 引导：**围绕目标产品安排材料与工艺方案，再通过打样、验证和生产确认，逐步推进。**

桌面横向四步，手机纵向。用文字与细线衔接，不做循环环形图。

| 步骤 | 正文 |
|---|---|
| 明确需求 | 确认用途、手感、重点性能和开发计划。 |
| 选材打样 | 安排材料组合，协调织造、染整及复合打样。 |
| 样品确认 | 对照目标检查性能与外观，调整方案并确认样品。 |
| 量产准备 | 核对材料规格、生产安排与检验要求。 |

“量产准备”与已完成量产分开，不暗示所有开发样品已经可直接大货交付。

### P05-03 环节衔接

- 标题：**把各环节接起来**
- 正文：**面料开发涉及多道工序。港翼围绕同一产品要求，协调材料、织造、染整和复合，让样品调整与生产要求能够传递到相应环节。**
- 图注字段：材料或加工环节名称、图片主体身份。

桌面一张宽幅生产细节图加一列文字；下方可用“材料 / 织造与染整 / 复合 / 成品检验”四个短标签。此处不重复解释纤维原理、复合参数，也不堆供应商 Logo。

### P05-04 量产确认

- 标题：**量产前，需要确认什么**

| 确认项 | 前台说明 |
|---|---|
| 样品与规格 | 对齐确认样品、材料规格及允许偏差。 |
| 工艺与外观 | 核对加工方式、颜色、手感和外观要求。 |
| 性能与检验 | 明确检测项目、方法及验收依据。 |

采用清晰的三行列表，右侧可放经脱敏的样卡或检验记录实拍。没有真实可公开记录时只显示列表，不伪造单据。

可选成果证据：经核实的批次对比、实际项目交付案例。未提供事实前，不写产能、交期保证、良率或“全流程自主生产”。

- 标题：**讨论开发与量产需求**
- 正文：**说明产品用途、目标性能、预计用量和时间安排，便于评估打样与生产方案。**

## 8. P06｜测试与认证

**任务：**让客户看懂结果如何得到、适用于哪个对象，以及有哪些检测或资质依据。

**布局顺序：**首屏 → 测试对象与工作方式 → 精选检测实例 → 认证与资质 → 资料咨询。

### P06-01 首屏

- 标题：**测试与认证**
- 副标题：**从材料筛选到成品面料，用测试确认表现，为选材与开发提供依据。**
- 图像：使用真实测试设备、试样或实验操作。照片身份准确；实验室招牌不作为唯一证明。

### P06-02 测什么，怎样测

- 标题：**围绕用途安排测试**
- 正文：**先明确材料将用于什么产品，再选择测试对象、项目与方法。开发过程中的样品对比，帮助调整材料与工艺；第三方检测则提供相应样品的独立检测结果。**

桌面左图右文。正文下方分两列：

- **开发测试：**比较材料、结构和工艺变化，观察样品表现。
- **第三方检测：**根据项目要求，安排样品检测并整理相应结果。

下方轻量展示关注项目：防水与透湿 / 防晒与导湿 / 强度与耐磨 / 层间结合与耐久 / 专业防护。标为“按产品需求选择的项目”，不得暗示全部已完成或都能由港翼内部实验室完成。

### P06-03 检测实例

- 标题：**检测结果，对应具体样品**
- 引导：**以下摘要展示部分样品的检测项目与结果。开发选材时，可进一步了解适用条件和配套资料。**

最多选择两至三个有完整依据的实例。每个实例横向一行或一块干净的图文区域，避免证书九宫格。显示字段：

1. 样品或材料名称。
2. 检测项目、结果与单位。
3. 方法、必要条件、检测机构及日期。
4. 一句话解释对选材的意义。
5. “了解对应材料”链接回 P02 / P03 / P04 或对应系列。

推荐候选：RPO-SOTEX 膜的目标 PFAS 检测；具有清楚样品映射的 OTTER 成品性能检测。仅为候选，本次不直接录入历史报告数值。T50-1、T50-2 或其他历史样品名称之间不得未经确认互换。

本页实例提供可追溯的摘要；技术专题可突出同一事实的产品意义，结果与方法应来自同一份记录，避免两处各写一套数字。完整报告、TDS、内部开发记录不公开下载。

### P06-04 认证与资质

- 标题：**认证与资质**
- 引导：**查看与具体材料、产品或生产环节有关的资质信息。**

只有核实主体、范围、有效期及展示授权的条目才出现。每个条目显示证书名称、持有人、覆盖对象与有效期；Logo 为辅助，不能单独作为内容。

SGS、CTTC 等在对应实例中标为检测机构，不与产品认证混排。合作方证书在这里明确标为对应合作方及适用环节。研发奖项归“研发成果”，不放进本栏。无可核实证书时，本模块暂不显示，页面仍保留“测试与认证”标题供后续扩展。

### P06-05 资料咨询

- 标题：**了解适用于你项目的测试资料**
- 正文：**提供产品用途或正在评估的面料，我们可以进一步沟通相应性能信息与测试资料。**
- 主链接：**咨询测试资料** → 合作咨询，带入“测试资料”主题。

**删减：**无对象的 Logo 墙、把检测报告称为认证、泛称所有产品通过同样测试、没有事实支撑的设备或实验室能力列表。

## 11. 实施与审阅顺序

1. **P01 概览与材料科技菜单。**先验证用户能否理解五个板块的关系，并检查全屏下宽度和密度。
2. **P02 膜技术。**确定技术图、正文与成果摘要的共用视觉样式。
3. **P03 高性能纤维。**审阅成果优先的呈现方式、材料名称及 RAYO 关联。
4. **P04 复合技术。**审阅手感案例与结构 tab，验证 RAYO、KAIS 可以自然纳入。
5. **P05 供应链、P06 测试与认证。**分别检查交付路径和证据表达，不合并成一个页面。
6. **全模块贯通。**检查旧链接、市场版本、移动端、首页入口和系列页关联。

每次审阅以整页和上下相邻模块为单位，避免只看一张局部卡片。先在本地按页实现，逐页确认后再讨论发布范围。

## 12. 验收标准

- 进入概览后可直接找到五个独立板块，理解材料工艺与开发交付的关系。
- 系列页负责用途，技术页负责方法和结果；不会要求客户在介绍页与数据库之间来回寻找基础解释。
- 高性能纤维容纳全部实际开发材料，品牌名称不造成材料身份或研发归属误解。
- 复合页不把固定的三层膜结构当作所有方案；不同结构示例与其图文一致。
- 所有公开结果对应具体对象和方法；数字区没有未经核实的数值、对比或认证状态。
- 字体、边距、图文对齐线与现有官网一致，超宽屏不出现小块内容漂在大面积空白中央。
- 手机端内容顺序清楚，tab、菜单与链接可通过触控和键盘操作；精简动画模式仍可阅读。
- 完整 TDS 与报告继续定向提供。现有公开图片未经身份核对不换成“港翼自有设施”描述。
- 实施时内容写入当前生产镜像使用的本地数据源，并同步处理回退文案；避免再次出现本地与生产版本混用。
- 不改动既有生产同步脚本和其他未提交工作；六页方案确认后再更新 PRD 对应章节。
