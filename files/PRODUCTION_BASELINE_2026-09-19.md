## 使用方式

`npm run review:local` 构建当前代码并启动预览。后续代码编辑后重新构建，浏览器刷新即可查看。

`npm run sync:public` 从正式官网刷新公开内容和引用媒体。此操作是只读拉取，不写生产；重新启动预览后应用新快照。新快照会替换本地内容基线，已有本地内容修改应先备份。

`node scripts/verify-production-preview.mjs` 将运行中的本地接口与上次生产快照、媒体校验值比对。开始做本地内容调整后，差异需按本次改动审阅，不能把所有差异都当成同步失败。

数据、快照和媒体均位于被 Git 忽略的 `preview.local/`。根目录原有 `db.json` 未改动，也不作为本次预览内容源。

不复制后台账号、客户咨询、邮件凭据及私有内容。本地咨询提交被禁用。产品应用目录保留公开接口快照，因为生产分类数量包含部分非公开记录，不能靠公开产品重建完全相同的统计；修改该页内容时编辑公开快照并重启预览，布局仍修改正常页面代码。
