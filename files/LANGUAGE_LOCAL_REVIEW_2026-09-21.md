# 语言入口与首次访问选择：本地实现

未发布生产。保留此前专业支持本地改动。

- 菜单：简体中文、繁體中文、English；桌面和手机一致，去掉菜单里的 locale 小字。
- 继续共用 CMS 页面结构、媒体和型号，路由为根路径、`/tw`、`/global`。既有其他语言市场配置保留。
- 明确的语言路径优先；未带语言前缀的首次访问，优先使用手动选择 Cookie，然后按服务器本地 IP 国家库匹配，失败后匹配浏览器语言。
- CN → 简体；HK/MO/TW → 繁体；其他已识别国家 → English。自动选择在公共 bootstrap 阶段完成，正文不会先显示简体再切换；不是在 HTML 请求之前判断。
- 自动选择响应 private/no-store；不把个性化选择写入公共缓存。IP 由 Express 按现有可信代理配置读取，不使用浏览器传来的国家参数，不调用外部 IP 查询服务。
- 繁体通过服务器 OpenCC 转换；CMS“多语言内容”里可看到自动结果占位并保存人工译文，手动译文优先。更新简体原文后新的文本自动转换。
- 浏览器不包含 OpenCC 字库或 IP 数据库。保持已有前台构建预算。
- 未新增地理定位权限、第三方翻译请求或新的字体下载。

## 运维

生产一层反向代理仍按现有部署规范使用 TRUST_PROXY=1，并确保源站应用端口仅允许可信代理访问；代理需提供真实访客 IP。当前修改只在本地验证，未改变生产代理配置。

IP 库为 geoip-country 5.0.202609190133 的国家级数据库，含 MaxMind GeoLite2 数据；其软件与数据条款在依赖包 LICENSE/EULA 中。部署及维护时按上游条款更新数据（包括旧数据的 30 天更换要求），不能长期锁定本次快照。IP 判断可能因 VPN 或数据库误差与用户所在地区不同，手动选择始终可用。

This product includes GeoLite2 Data created by MaxMind, available from https://www.maxmind.com/.

## 验证范围与限制

自动测试覆盖 IPv4/IPv6、CN/HK/MO/TW/US、浏览器回退、Cookie 优先、停用语言、路径参数与锚点保留、个性化响应缓存、非可信代理头、繁体自动转换及人工覆盖。

浏览器已检查繁体支持页与菜单顺序、英文切换及重新打开无前缀地址后的语言记忆。繁体转换为字词转换，不等于所有地区用语均已人工审校。英文站原有正文缺译仍存在，这次仅补相关公共界面词条，不声称已完成整站英译。
